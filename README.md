# RT Simulator

Simulasi naratif jadi Ketua RT selama 52 minggu. Satu file statis (`index.html`), tanpa backend.
Progres pemain tersimpan di browser masing-masing (localStorage).

## Deploy (Vercel)
- Framework Preset: **Other**
- Build Command: kosong
- Output Directory: kosong (root)

Setiap push ke branch `main` otomatis membuat deployment baru.

## Update versi
Ganti `index.html` dengan build terbaru, lalu commit ke `main`.
